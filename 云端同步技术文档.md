## 技术架构概述

### 核心技术栈

- **后端数据库**: Supabase (PostgreSQL)
- **实时通信**: Supabase Realtime (基于 PostgreSQL 的变更通知)
- **本地存储**: IndexedDB (使用 Dexie.js)
- **客户端存储**: localStorage (用于时间戳和快照名称跟踪)
- **同步策略**: LWW (Last Write Wins) - 基于服务器时间戳

### 架构特点

1. **单账号多设备同步**: 同一用户账号可在多个设备上同步数据
2. **实时检测更新**: 使用 Supabase Realtime 监听数据库变更
3. **快照版本管理**: 通过快照名称（snapshot_label）跟踪版本变化
4. **冲突解决**: 基于服务器时间戳的 LWW 策略
5. **离线支持**: 本地数据存储在 IndexedDB，支持离线操作

## 云端同步机制

### 核心概念

1. **时间戳跟踪**: 使用 `lastSyncTimestamp` 记录本地最后同步的服务器时间戳
2. **快照名称跟踪**: 使用 `lastSnapshotName` 记录最后已知的快照名称
3. **数据比较**: 保存前比较本地数据和云端数据，检测冲突
4. **自动冲突解决**: 如果云端数据更新，自动加载最新数据

### 保存流程 (`cloudSave`)

```javascript
export async function cloudSave() {
  // 1. 获取本地数据
  const rows = await getAllRows();
  const cats = readCats();
  const view = readView();

  // 2. 查询云端最新快照
  const { data: cloudData } = await supabase
    .from(SUPABASE_TABLE)
    .select('payload, updated_at, updated_by_name')
    .eq('key', SUPABASE_DEFAULT_KEY)
    .order('updated_at', { ascending: false })
    .limit(1);

  const cloudRow = cloudData?.[0];

  // 3. 检查数据库是否有更新（检测其他设备的改动）
  if (cloudRow) {
    const cloudTime = new Date(cloudRow.updated_at).getTime();
    
    // 4. 数据比较
    if (cloudRow.payload) {
      const latestRows = cloudRow.payload.rows || [];
      const latestCats = cloudRow.payload.cats || [];
      const latestView = cloudRow.payload.view || {};

      // 标准化并比较数据
      const rowsEqual = compareRows(rows, latestRows);
      const catsEqual = compareCats(cats, latestCats);
      const viewEqual = compareView(view, latestView);
      const dataContentEqual = rowsEqual && catsEqual && viewEqual;

      // 5. 冲突检测和处理
      if (dataContentEqual) {
        // 数据内容相同，但时间戳可能更新了
        if (cloudTime > lastSyncTimestamp) {
          // 其他设备保存了相同数据，更新本地时间戳
          lastSyncTimestamp = cloudTime;
          localStorage.setItem('last_sync_time', String(cloudTime));
          alert('没有数据改动，无需保存');
          return;
        }
      } else {
        // 数据内容不同，检查冲突
        if (cloudTime > lastSyncTimestamp) {
          // 云端数据更新，自动加载最新数据（LWW策略）
          await cloudLoad(SUPABASE_DEFAULT_KEY, false);
          alert('已自动加载云端最新数据，请重新修改并保存');
          return;
        }
      }
    }
  }

  // 6. 保存数据到云端
  const payload = {
    ver: 1,
    rows: rows,
    cats: cats,
    view: view
  };

  const { data: saved, error } = await supabase
    .from(SUPABASE_TABLE)
    .upsert({
      key: SUPABASE_DEFAULT_KEY,
      owner_id: userId,
      payload: payload,
      updated_at: new Date().toISOString(),
      updated_by_name: userName
    }, { onConflict: 'key' })
    .select('updated_at')
    .single();

  // 7. 更新本地时间戳和快照名称
  const serverTime = new Date(saved.updated_at).getTime();
  lastSyncTimestamp = serverTime;
  localStorage.setItem('last_sync_time', String(serverTime));
  
  const snapshotName = generateSnapshotName(userName, saved.updated_at);
  saveLastSnapshotName(snapshotName);
}
```

### 数据比较函数

```javascript
// 标准化行数据（只比较数据字段，忽略元数据）
function normalizeRow(r) {
  if (!r) return null;
  return {
    phone: String(r.phone || '').trim(),
    owner: String(r.owner || '').trim(),
    wx_real: String(r.wx_real || '').trim(),
    wx_name: String(r.wx_name || '').trim(),
    xhs_name: String(r.xhs_name || '').trim(),
    note1: String(r.note1 || '').trim(),
    row_color: String(r.row_color || '').trim(),
    order: String(r.order ?? 0).trim()
  };
}

// 排序行数据（按 phone 排序，确保顺序一致）
function sortRows(rowsData) {
  return rowsData
    .map(normalizeRow)
    .filter(r => r !== null)
    .sort((a, b) => {
      const phoneA = a.phone || '';
      const phoneB = b.phone || '';
      if (phoneA !== phoneB) return phoneA.localeCompare(phoneB);
      const ownerA = a.owner || '';
      const ownerB = b.owner || '';
      if (ownerA !== ownerB) return ownerA.localeCompare(ownerB);
      return (a.xhs_name || '').localeCompare(b.xhs_name || '');
    });
}

// 比较行数据
function compareRows(currentRows, latestRows) {
  const currentRowsData = sortRows(currentRows);
  const latestRowsData = sortRows(latestRows);
  return JSON.stringify(currentRowsData) === JSON.stringify(latestRowsData);
}
```

## 云端读取机制

### 核心概念

1. **时间戳检查**: 静默加载时只加载比本地时间戳新的数据
2. **手动加载**: 手动加载时强制加载最新数据，不检查时间戳
3. **数据验证**: 加载后验证数据是否正确写入本地数据库
4. **界面刷新**: 加载完成后自动刷新界面

### 加载流程 (`cloudLoad`)

```javascript
export async function cloudLoad(keyOrSilent = SUPABASE_DEFAULT_KEY, silent = false) {
  // 1. 参数处理（兼容旧调用方式）
  let key = SUPABASE_DEFAULT_KEY;
  let isSilent = false;
  
  if (typeof keyOrSilent === 'boolean') {
    isSilent = keyOrSilent;
    key = SUPABASE_DEFAULT_KEY;
  } else if (typeof keyOrSilent === 'string') {
    key = keyOrSilent;
    isSilent = silent;
  }

  // 2. 检查本地是否有未保存修改
  if (!isSilent && isLocalDirty()) {
    const ok = confirm('本地有未保存修改，加载云端数据将覆盖本地修改，是否继续？');
    if (!ok) return;
  }

  // 3. 更新 lastSyncTimestamp（从 localStorage 重新读取，确保多标签页同步）
  const savedTime = localStorage.getItem('last_sync_time');
  if (savedTime) lastSyncTimestamp = parseInt(savedTime);

  // 4. 查询云端数据
  const { data, error } = await supabase
    .from(SUPABASE_TABLE)
    .select('payload, updated_at, updated_by_name')
    .eq('key', key)
    .order('updated_at', { ascending: false })
    .limit(1)
    .maybeSingle();

  if (error) throw error;
  if (!data) {
    if (!isSilent) alert('云端无数据');
    return;
  }

  const row = data;
  const serverTime = new Date(row.updated_at).getTime();

  // 5. 时间戳检查（静默加载时）
  if (isSilent && serverTime <= lastSyncTimestamp) {
    console.log('云端数据不比本地新，跳过加载');
    return;
  }

  // 6. 写入本地数据库
  const payload = row.payload || {};
  
  // iOS Safari 兼容性：添加重试机制
  let retryCount = 0;
  const maxRetries = 3;
  while (retryCount < maxRetries) {
    try {
      await overwriteAllRows(payload.rows || []);
      break;
    } catch (writeErr) {
      retryCount++;
      if (retryCount >= maxRetries) {
        throw new Error(`数据写入失败，已重试 ${maxRetries} 次`);
      }
      await new Promise(resolve => setTimeout(resolve, 500 * retryCount));
    }
  }

  // 7. 验证数据是否已写入
  const verifyRows = await getAllRows();
  if (verifyRows.length !== (payload.rows || []).length) {
    console.warn('数据条数不匹配，可能写入不完整');
    // iOS 设备特殊处理
    if (/iPhone|iPad|iPod/i.test(navigator.userAgent)) {
      await overwriteAllRows(payload.rows || []);
    }
  }

  // 8. 更新配置
  if (payload.cats) {
    saveCats(payload.cats, true);
  }
  if (payload.view) {
    saveView(payload.view, true);
  }

  // 9. 更新本地时间戳和快照名称
  lastSyncTimestamp = serverTime;
  localStorage.setItem('last_sync_time', String(serverTime));
  
  const snapshotName = payload.snapshot_label || 
    generateSnapshotName(row.updated_by_name || '未知用户', row.updated_at);
  saveLastSnapshotName(snapshotName);

  // 10. 清除脏标记并刷新界面
  clearDirty();
  if (window.renderTable) await window.renderTable();
  if (window.refreshFilters) await window.refreshFilters();

  // 11. 提示用户
  if (isSilent) {
    showToast(`已同步 ${row.updated_by_name || '其他设备'} 的修改`);
  } else {
    alert('已加载云端最新数据');
  }
}
```

### 快照名称生成

```javascript
function generateSnapshotName(userName, updatedAt) {
  const formatDateTime = (ts) => {
    try {
      const d = new Date(ts);
      const Y = d.getFullYear();
      const M = String(d.getMonth() + 1).padStart(2, '0');
      const D = String(d.getDate()).padStart(2, '0');
      const h = String(d.getHours()).padStart(2, '0');
      const m = String(d.getMinutes()).padStart(2, '0');
      return `${Y}${M}${D}${h}${m}`;
    } catch {
      return '';
    }
  };
  
  const dateTimeStr = formatDateTime(updatedAt);
  return `${userName} ${dateTimeStr}`;
}
```

## 检测更新机制

### 核心概念

1. **快照名称跟踪**: 通过比较快照名称（snapshot_label）检测是否有新快照
2. **时间戳跟踪**: 通过比较服务器时间戳检测是否有更新
3. **版本去重**: 使用版本号（而不是 key）来判断是否已检查过
4. **自动更新提示**: 检测到更新时弹出对话框提示用户

### 版本检测流程 (`updateCloudSnapshotInfo`)

```javascript
async function updateCloudSnapshotInfo() {
  // 1. 从 localStorage 获取本地当前加载的云端快照信息
  const currentCloudSnapshot = localStorage.getItem('xhs_current_cloud_snapshot');
  const currentCloudVersion = localStorage.getItem('xhs_current_cloud_version');

  // 2. 获取云端最新的快照信息
  let latestCloudSnapshot = '未知';
  let latestCloudVersion = '未知';
  let latestSnapshotData = null;

  if (supabase) {
    const currentUserId = await getCurrentUserId();
    if (currentUserId) {
      const { data: latestSnapshot, error } = await supabase
        .from(SUPABASE_TABLE)
        .select('key, payload, updated_at')
        .eq('owner_id', currentUserId)
        .order('updated_at', { ascending: false })
        .limit(1);

      if (!error && latestSnapshot && latestSnapshot.length > 0) {
        const snapshot = latestSnapshot[0];
        latestCloudSnapshot = snapshot.key || '未知';
        latestCloudVersion = snapshot.payload?.snapshot_label || '未知';
        latestSnapshotData = snapshot;
      }
    }
  }

  // 3. 检测版本差异
  if (latestSnapshotData && latestCloudSnapshot !== '未知' && 
      latestCloudVersion !== '未知' && !isAutoUpdating) {
    
    // 比较版本：主要比较 snapshot_label（版本号）
    const isVersionDifferent = currentCloudVersion !== latestCloudVersion;
    
    // 使用版本号（snapshot_label）来判断是否已检查过
    const hasCheckedThisVersion = lastCheckedSnapshotKey === latestCloudVersion;

    if (isVersionDifferent && !hasCheckedThisVersion) {
      // 4. 标记正在自动更新，避免重复触发
      isAutoUpdating = true;
      lastCheckedSnapshotKey = latestCloudVersion;

      // 5. 弹出对话框提示用户
      const shouldUpdate = confirm(
        '检测到云端有更新的快照\n\n' +
        `本地版本：${currentCloudSnapshot || 'default'} (${currentCloudVersion || '-'})\n` +
        `云端版本：${latestCloudSnapshot} (${latestCloudVersion})\n\n` +
        '是否立即更新本地数据？\n\n' +
        '注意：更新将覆盖本地数据'
      );

      if (shouldUpdate) {
        // 6. 用户确认更新，加载云端快照
        await cloudLoad(latestCloudSnapshot);
      } else {
        // 用户取消时也记录已检查，避免频繁弹出
        lastCheckedSnapshotKey = latestCloudVersion;
      }

      // 7. 重置自动更新标志
      isAutoUpdating = false;
    }
  }
}
```

## 多设备快照更新机制

### 核心概念

1. **Realtime 监听**: 使用 Supabase Realtime 监听数据库变更
2. **快照名称变化检测**: 通过比较快照名称检测是否有新快照
3. **时间戳更新检测**: 通过比较时间戳检测是否有更新
4. **自动同步**: 检测到更新时自动提示用户并加载最新数据

### 自动同步初始化 (`initAutoSync`)

```javascript
export async function initAutoSync() {
  // 1. 检查是否已启动
  if (isAutoSyncStarted) {
    console.log('自动同步已启动，跳过重复初始化');
    return;
  }

  // 2. 检查 Supabase 和用户登录状态
  if (!supabase) {
    console.warn('Supabase 未配置，无法启动自动同步');
    return;
  }

  const myUid = await getCurrentUserId();
  if (!myUid) {
    console.warn('用户未登录，无法启动自动同步');
    return;
  }

  isAutoSyncStarted = true;

  // 3. 初始化时间戳和快照名称
  const savedTime = localStorage.getItem('last_sync_time');
  if (savedTime) lastSyncTimestamp = parseInt(savedTime);

  const lastSnapshotName = getLastSnapshotName();

  // 4. 如果没有保存的快照名称，尝试从云端获取
  if (!lastSnapshotName) {
    try {
      const { data } = await supabase
        .from(SUPABASE_TABLE)
        .select('payload, updated_at, updated_by_name')
        .eq('key', SUPABASE_DEFAULT_KEY)
        .order('updated_at', { ascending: false })
        .limit(1)
        .maybeSingle();

      if (data && data.payload) {
        const snapshotName = data.payload.snapshot_label || 
          generateSnapshotName(data.updated_by_name || '未知用户', data.updated_at);
        saveLastSnapshotName(snapshotName);
      }
    } catch (err) {
      console.warn('初始化时获取快照名称失败:', err);
    }
  }

  // 5. 创建 Realtime 订阅
  const channel = supabase
    .channel('smart-auto-sync')
    .on(
      'postgres_changes',
      { 
        event: '*', 
        schema: 'public', 
        table: SUPABASE_TABLE, 
        filter: `key=eq.${SUPABASE_DEFAULT_KEY}` 
      },
      async (evt) => {
        // 6. 处理数据库变更事件
        const newRow = evt.new;
        if (!newRow) return;

        const serverTime = new Date(newRow.updated_at).getTime();

        // 7. 更新 lastSyncTimestamp（从 localStorage 重新读取，确保多标签页同步）
        const savedTime = localStorage.getItem('last_sync_time');
        const currentLastSync = savedTime ? parseInt(savedTime) : 0;
        lastSyncTimestamp = currentLastSync;

        // 8. 获取当前快照名称
        const currentSnapshotName = getLastSnapshotName();

        // 9. 生成新的快照名称（用于比较）
        const newSnapshotName = newRow.payload?.snapshot_label || 
          generateSnapshotName(newRow.updated_by_name || '未知用户', newRow.updated_at);

        // 10. 关键检测：快照名称是否改变（这是检测新快照的主要方式）
        const snapshotNameChanged = currentSnapshotName !== newSnapshotName;

        // 11. 如果快照名称改变，说明有新快照，需要更新
        if (!snapshotNameChanged && serverTime <= lastSyncTimestamp) {
          console.log('快照名称未改变且时间戳不比本地新，跳过自动同步');
          return;
        }

        // 12. 快照名称改变或时间戳更新，需要同步
        const who = newRow.updated_by_name || '其他设备';

        if (isLocalDirty()) {
          // 本地有未保存修改，弹出提示要求用户更新
          const ok = confirm(
            `检测到最新快照已更新\n\n"${who}" 刚刚保存了新快照。\n\n` +
            `点击【确定】自动加载最新快照（本地未保存的修改将被覆盖）\n\n` +
            `点击【取消】稍后手动加载`
          );
          if (ok) {
            lastSyncTimestamp = 0;
            localStorage.setItem('last_sync_time', '0');
            const loadFunc = window.cloudLoad || cloudLoad;
            await loadFunc(SUPABASE_DEFAULT_KEY, false);
          } else {
            showToast(`${who} 更新了快照，请稍后手动加载`);
          }
          return;
        }

        // 13. 本地没有未保存修改，弹出提示并自动加载最新数据
        const ok = confirm(
          `检测到最新快照已更新\n\n"${who}" 刚刚保存了新快照。\n\n` +
          `点击【确定】自动加载最新快照\n\n` +
          `点击【取消】稍后手动加载`
        );

        if (ok) {
          lastSyncTimestamp = 0;
          localStorage.setItem('last_sync_time', '0');
          const loadFunc = window.cloudLoad || cloudLoad;
          await loadFunc(SUPABASE_DEFAULT_KEY, false);
        } else {
          showToast(`${who} 更新了快照，请稍后手动加载`);
        }
      }
    )
    .subscribe((status) => {
      console.log('Realtime 订阅状态:', status);
      if (status === 'SUBSCRIBED') {
        console.log('Realtime 订阅成功，开始监听数据变化');
      } else if (status === 'CHANNEL_ERROR') {
        console.error('Realtime 订阅失败');
      }
    });

  // 14. 保存 channel 引用，防止被垃圾回收
  window._syncChannel = channel;
}
```

### 1. 配置文件 (`config.js`)

### 4. 数据写入本地数据库 (`data.js`)

```javascript
import Dexie from 'https://esm.sh/dexie@4.0.8';

const db = new Dexie(DB_NAME);
db.version(2).stores({
  rows: "id,order,phone,owner,wx_real,wx_name,xhs_name,note1,row_color,updated_at",
  meta: "key"
});

export async function overwriteAllRows(rows) {
  await ensureDbReady();
  
  try {
    await db.transaction('rw', db.rows, async (tx) => {
      // 先清空
      await tx.rows.clear();
      
      // 如果有数据，批量添加
      if (rows && rows.length > 0) {
        const batchSize = 100;
        for (let i = 0; i < rows.length; i += batchSize) {
          const batch = rows.slice(i, i + batchSize);
          await tx.rows.bulkAdd(batch);
        }
      }
    });
  } catch (err) {
    console.error('数据写入失败:', err);
    // iOS Safari 可能需要重试
    if (err.name === 'QuotaExceededError' || err.name === 'UnknownError') {
      await db.rows.clear();
      if (rows && rows.length > 0) {
        await db.rows.bulkAdd(rows);
      }
    } else {
      throw err;
    }
  }
}
```

## 常见问题和解决方案

### 1. 多标签页同步问题

**问题**: 多个标签页打开时，时间戳不同步

**解决方案**: 
- 每次操作前从 `localStorage` 重新读取 `lastSyncTimestamp`
- 使用 `localStorage` 作为单一数据源

```javascript
// 更新 lastSyncTimestamp（从 localStorage 重新读取，确保多标签页同步）
const savedTime = localStorage.getItem('last_sync_time');
if (savedTime) lastSyncTimestamp = parseInt(savedTime);
```

### 2. iOS Safari 数据写入失败

**问题**: iOS Safari 在写入大量数据时可能失败

**解决方案**:
- 添加重试机制
- 分批写入数据
- 验证数据写入结果

```javascript
let retryCount = 0;
const maxRetries = 3;
while (retryCount < maxRetries) {
  try {
    await overwriteAllRows(payload.rows || []);
    break;
  } catch (writeErr) {
    retryCount++;
    if (retryCount >= maxRetries) {
      throw new Error(`数据写入失败，已重试 ${maxRetries} 次`);
    }
    await new Promise(resolve => setTimeout(resolve, 500 * retryCount));
  }
}
```

### 3. Realtime 订阅被垃圾回收

**问题**: Realtime channel 可能被垃圾回收，导致监听失效

**解决方案**: 保存 channel 引用到全局变量

```javascript
// 保存 channel 引用，防止被垃圾回收
window._syncChannel = channel;
```

### 4. 版本检测重复触发

**问题**: 检测到更新后频繁弹出提示

**解决方案**: 使用版本号（而不是 key）来标记已检查

```javascript
// 使用版本号（snapshot_label）来判断是否已检查过
const hasCheckedThisVersion = lastCheckedSnapshotKey === latestCloudVersion;

if (isVersionDifferent && !hasCheckedThisVersion) {
  // 标记已检查
  lastCheckedSnapshotKey = latestCloudVersion;
  // 弹出提示...
}
```

### 5. 数据冲突处理

**问题**: 多个设备同时修改数据，如何处理冲突

**解决方案**: 使用 LWW (Last Write Wins) 策略，基于服务器时间戳

```javascript
if (cloudTime > lastSyncTimestamp) {
  // 云端数据更新，自动加载最新数据（LWW策略）
  await cloudLoad(SUPABASE_DEFAULT_KEY, false);
  alert('已自动加载云端最新数据，请重新修改并保存');
  return;
}
```

### 6. 快照名称变化检测

**问题**: 如何准确检测是否有新快照

**解决方案**: 同时检测快照名称变化和时间戳更新

```javascript
// 关键检测：快照名称是否改变（这是检测新快照的主要方式）
const snapshotNameChanged = currentSnapshotName !== newSnapshotName;

// 如果快照名称改变，说明有新快照，需要更新
if (!snapshotNameChanged && serverTime <= lastSyncTimestamp) {
  console.log('快照名称未改变且时间戳不比本地新，跳过自动同步');
  return;
}
```
